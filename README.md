# AI-Driven Healthcare Chatbot

## Introduction
In an era marked by rapid technological advancement, integrating artificial intelligence (AI) into healthcare has become a transformative force. This project aims to develop an innovative healthcare chatbot to facilitate symptom-based disease diagnosis and provide personalized healthcare recommendations. Leveraging natural language processing (NLP) and machine learning (ML), the chatbot acts as a virtual medical assistant, enabling users to input symptoms and receive tailored health insights. Our solution focuses on improving accessibility, efficiency, and user empowerment in managing health effectively.

## Purpose of the Project
The proposed idea is to create a medical chatbot using Artificial Intelligence to diagnose diseases and provide basic details about them before consulting a doctor. This aims to reduce healthcare costs and improve accessibility to medical knowledge.

## Code Implementation

### Project Structure

The project directory is organized as follows:

- **healthcare-chatbot/public**: Contains the client-side files.
  - **index.html**: The main HTML file that structures the web page.
  - **script.js**: JavaScript file responsible for client-side logic and interactions.
  - **styles.css**: CSS file for styling the web page.

- **healthcare-chatbot/server**: Contains the server-side files.
  - **server.js**: The main Node.js server file that handles backend logic and API requests.
  - **node_modules**: Directory containing the Node.js dependencies.
  - **.env**: Environment file storing the API key and other sensitive information.
  - **package.json** and **package-lock.json**: Configuration files for managing project dependencies and scripts.

- **API.rtf**: Documentation file containing details about the API used in the project.
